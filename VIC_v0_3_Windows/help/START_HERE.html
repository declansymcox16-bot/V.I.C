VIC v0.3 — Start Here

  1. Extract the complete ZIP.
  2. Run INSTALL_VIC.bat.
  3. Run INSTALL_FFMPEG.bat if needed.
  4. Run CHECK_SYSTEM.bat.
  5. Run START_VIC.bat.
  6. Wait until Local Worker is online.
  7. Add a source and choose Automatic or Local Worker.
  8. Click Test, then Start.

Another worker PC

Copy the complete folder to that PC. Set dashboard_url in config\worker.json to the dashboard PC IP address. Keep the same cluster token. Run START_WORKER.bat.

Desktop sound

Select an audio device exposed by Windows, such as Stereo Mix or a virtual audio cable. VIC cannot invent a loopback device if Windows does not provide one.
