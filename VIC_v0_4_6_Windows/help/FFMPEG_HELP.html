FFmpeg

Run INSTALL_FFMPEG.bat. It uses WinGet to install Gyan.FFmpeg. Close old command windows afterwards and run CHECK_SYSTEM.bat.

VIC searches PATH, its own tools\ffmpeg\bin folder and common WinGet package locations.

GPU encoder diagnostic

Run TEST_GPU_ENCODER.bat on the computer doing the recording. VIC v0.4.6 checks every FFmpeg installation and prefers one whose NVENC, AMF or Quick Sync encoder passes a real runtime test. The Worker details page shows the chosen path and the exact CPU-fallback reason.
