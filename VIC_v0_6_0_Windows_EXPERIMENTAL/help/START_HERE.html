VIC v0.3.1 — Start Here

  1. Extract the ZIP into a new folder.
  2. Double-click START_VIC.bat.
  3. If packages are missing, the installer opens automatically.
  4. Install FFmpeg with INSTALL_FFMPEG.bat when required.
  5. Wait for Local PC (this computer) to appear online.

First screen test

  1. Add source.
  2. Choose Desktop, monitor or application window.
  3. Select Local PC (this computer).
  4. Press Load worker devices.
  5. Choose the whole desktop or one monitor.
  6. Select optional loopback audio.
  7. Save, Test and Start.
  8. Open the Live tab in a separate browser tab.

Find files

Open the Recordings tab. It shows the recording path reported by each worker.

Screen audio dropdown

After selecting a worker, press Load worker devices. The screen audio dropdown includes microphones/audio inputs and speaker/headphone outputs. Microphones are added to the screen MKV. Speaker loopback is stored as a matching companion WAV file beside the screen recording and drives the live volume meter.

Shared speaker piggybacking

VIC opens each speaker or headphone output once and shares that audio with all screen sources, standalone speaker recordings, live meters and mass-capture jobs using it. This lets several VIC sources piggyback on audio that is already playing without fighting each other for the Windows device.

If Windows still reports 0x8889000A when no other VIC speaker source is running, another application is holding the device in exclusive mode.

Test All, Start All and Stop All

The Dashboard has three bulk buttons. Test All sends a short test to every source, Start All starts all inactive sources, and Stop All stops every active test or recording.

Physical monitor size

VIC now asks Windows for the active physical signal mode instead of the DPI-scaled desktop size. A 4096×2160 display at 150% scaling should therefore be listed and captured as 4096×2160.

Faster meters and Live All

Audio levels now report about four times per second while a worker is online. The Dashboard has a larger Audio level column. Open Live All to see all latest source previews, states and audio meters together. Individual Live pages remain available.

Live All control room

Live All now has Test All, Start All and Stop All beside Full screen. Every card has its own Test, Start and Stop buttons. A pulsing green corner dot means recording, amber means testing or changing state, red means failed, and grey means inactive. The green border glow makes active recordings easy to spot.

Cleanup and website sources

VIC v0.3.8 adds safe history cleanup throughout the Dashboard, Live, Live All, Jobs and Workers pages. Recording-file deletion is separated and clearly marked as permanent. Website sources now support a single page, a playlist, or an upcoming scheduled livestream.

Editing and optional website login

Use Edit beside a source to change its name, worker and capture settings. Website sources can remain signed out, always use a selected browser/cookies file, or automatically retry with account access only after a login, age-verification or private-content error.

v0.4.0 connection and reliability

Second PCs can now find the main Dashboard automatically. Run START_WORKER.bat; use SETUP_WORKER_GUI.bat only as a fallback. STOP_VIC.bat now tracks process IDs, stops process trees and verifies the result.

The Edit-page Internal Server Error has been repaired. Future Dashboard errors are recorded in logs\dashboard_error.log.

v0.4.4 traceback fixes

The Edit page no longer conflicts with Flask's internal source parameter, and mass-transfer version checking now imports Python's re module correctly. Run TEST_DASHBOARD_FIXES.bat for a safe test using temporary data.

v0.4.7 GPU detection fix

Corrects false CPU fallback caused by double-escaped encoder-list regular expressions. The real encoder runtime test is now authoritative.

v0.5.0 faster parallel transfers

Workers now move up to three files at once by default. Worker Setup allows 1-6 simultaneous transfers. Transfer chunks are 4 MB, progress reporting is non-blocking, and the Recordings queue updates every 250 milliseconds with live speed and ETA.

v0.5.1 Retry All and 12 parallel slots

The transfer queue includes Retry All Failed / Stuck. It retries failed items and progress that has been stale for 30 seconds while leaving healthy active transfers alone. Worker Setup now offers 1-12 simultaneous transfers per worker; 4 is the fresh-install default.

v0.6.0 Experimental portable safety bundle

This separate-folder release adds source enable/archive/favourites, source import/export, automatic post-record movement, storage tests, protected recordings, a restorable VIC recycle bin, portable config backups, worker-copy ZIPs and an embedded v0.5.1 rollback package.

Run ROLLBACK_TO_V0_5_1.bat after stopping VIC to extract the previous working release beside this folder.
