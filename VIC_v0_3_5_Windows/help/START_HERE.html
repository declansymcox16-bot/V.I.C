VIC v0.3.1 — Start Here

  1. Extract the ZIP into a new folder.
  2. Double-click START_VIC.bat.
  3. If packages are missing, the installer opens automatically.
  4. Install FFmpeg with INSTALL_FFMPEG.bat when required.
  5. Wait for Local PC (this computer) to appear online.

First screen test

  1. Add source.
  2. Choose Desktop, monitor or application window.
  3. Select Local PC (this computer).
  4. Press Load worker devices.
  5. Choose the whole desktop or one monitor.
  6. Select optional loopback audio.
  7. Save, Test and Start.
  8. Open the Live tab in a separate browser tab.

Find files

Open the Recordings tab. It shows the recording path reported by each worker.

Screen audio dropdown

After selecting a worker, press Load worker devices. The screen audio dropdown includes microphones/audio inputs and speaker/headphone outputs. Microphones are added to the screen MKV. Speaker loopback is stored as a matching companion WAV file beside the screen recording and drives the live volume meter.

Shared speaker piggybacking

VIC opens each speaker or headphone output once and shares that audio with all screen sources, standalone speaker recordings, live meters and mass-capture jobs using it. This lets several VIC sources piggyback on audio that is already playing without fighting each other for the Windows device.

If Windows still reports 0x8889000A when no other VIC speaker source is running, another application is holding the device in exclusive mode.

Test All, Start All and Stop All

The Dashboard has three bulk buttons. Test All sends a short test to every source, Start All starts all inactive sources, and Stop All stops every active test or recording.

Physical monitor size

VIC now asks Windows for the active physical signal mode instead of the DPI-scaled desktop size. A 4096×2160 display at 150% scaling should therefore be listed and captured as 4096×2160.
