Live view, audio meter and recordings

Live tab

Start a source, open Live, then choose Open live tab. VIC displays a refreshed JPEG preview, job status, output path and an audio meter. It is intended for monitoring rather than zero-delay playback.

Audio meter

The meter is available when a screen, camera or audio source has a selected audio input. For normal speaker sound, Windows usually needs Stereo Mix or a loopback/virtual-audio input. A stationary empty bar can mean silence, the wrong device or no meter support for that source type.

Recordings tab

The Recordings tab lists files reported by every worker. The full path tells you exactly where each file is stored. Press Open folder on worker to open Explorer on that worker PC.

Remote workers

A remote worker's files remain on that PC. Use a shared path such as \\SERVER\Recordings when all computers need access to the same storage.

Screen audio dropdown

After selecting a worker, press Load worker devices. The screen audio dropdown includes microphones/audio inputs and speaker/headphone outputs. Microphones are added to the screen MKV. Speaker loopback is stored as a matching companion WAV file beside the screen recording and drives the live volume meter.

Shared speaker piggybacking

VIC opens each speaker or headphone output once and shares that audio with all screen sources, standalone speaker recordings, live meters and mass-capture jobs using it. This lets several VIC sources piggyback on audio that is already playing without fighting each other for the Windows device.

If Windows still reports 0x8889000A when no other VIC speaker source is running, another application is holding the device in exclusive mode.

Faster meters and Live All

Audio levels now report about four times per second while a worker is online. The Dashboard has a larger Audio level column. Open Live All to see all latest source previews, states and audio meters together. Individual Live pages remain available.
