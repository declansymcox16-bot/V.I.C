Worker PCs

A worker is a computer that performs the actual ingest or recording task. Sources can be assigned manually or automatically.

The dashboard sends pending jobs to the selected worker. The worker starts FFmpeg or yt-dlp, reports status and output paths, and receives stop commands.

A local file path must exist on the selected worker. For multiple PCs, use a shared path such as \\SERVER\Media\clip.mp4 or place the file on that worker.

Clearing old worker entries

The Workers page can forget one offline worker or clear every offline worker entry. A worker automatically appears again when its START_WORKER.bat reconnects.

Automatic network discovery

Remote workers first try the saved Dashboard address, then use LAN broadcast and a private-subnet scan. The discovered address is saved automatically. A copied folder also receives a new worker identity on the new computer.

Use SETUP_WORKER_GUI.bat for an Auto Find, Test Address and Save window.

Compatible FFmpeg and Worker-only start

Worker Setup can use Automatic compatible, Pinned/manual, or Newest installed FFmpeg selection. Automatic compatible tests all available copies and remembers the newest one that works with that worker's existing graphics driver.

The Open Worker BAT Only button saves the setup and launches only START_WORKER.bat. It does not start the main Dashboard.
