VIC — VIDEO INGEST CLUSTER
WINDOWS v0.2 — MULTI-MEDIA TEST BUILD
=====================================

You can test this version without an RTSP camera.

SUPPORTED INPUTS
----------------
• Local video or audio files
• Full Windows desktop capture
• Application/window capture
• Webcam, USB camera, HDMI capture card or OBS Virtual Camera
• Microphone/audio device
• RTSP/IP camera
• HTTP/HLS, SRT, UDP, RTP and other FFmpeg-readable network streams
• Watched folders that copy newly added media into VIC storage

QUICK START
-----------
1. Extract the ZIP.
2. Run INSTALL_VIC.bat.
3. Run INSTALL_FFMPEG.bat if FFmpeg is missing.
4. Run CHECK_SYSTEM.bat.
5. Run START_VIC.bat.

EASIEST TEST
------------
Add Media Source > Video or audio file > Browse > choose a file > Save > Test > Start.

HELP
----
Use Help inside VIC, hover over (?) symbols, or run OPEN_HELP.bat.

WORKERS
-------
Worker PCs register and appear in v0.2. Remote worker job execution is planned
for the next cluster version; v0.2 records on the dashboard PC.
