VIC v0.2 — Start Here

Install

  1. Extract the complete ZIP.
  2. Run INSTALL_VIC.bat.
  3. Run INSTALL_FFMPEG.bat if FFmpeg is missing.
  4. Close old command windows.
  5. Run CHECK_SYSTEM.bat.
  6. Run START_VIC.bat.

Easiest first test

  1. Click + Add media source.
  2. Choose Video or audio file.
  3. Click Browse.
  4. Select a media file.
  5. Save it.
  6. Click Test.
  7. Click Start.
  8. After a short time click Stop.
  9. Open Recordings.

You do not need an RTSP camera for this test.
