Troubleshooting

FFmpeg not found

Run INSTALL_FFMPEG.bat, close old windows, then run CHECK_SYSTEM.bat.

Test failed

Read the complete error shown in VIC. Source logs are also stored in the logs folder.

No camera devices appear

Confirm Windows can see the webcam/capture card, close software already using it, then click Detect devices again.

Window capture fails

Use the exact title shown in the program title bar. Test full desktop capture first.

Recording will not play

Stop the recording cleanly before opening it. VIC uses MKV because it is safer if a PC or program stops unexpectedly.
