Adding media sources

Video or audio file

Use an existing file such as MP4, MKV, MOV, AVI, MP3 or WAV. This is the easiest test.

Desktop or application window

Records the Windows desktop or a program whose exact window title you enter. Advanced X/Y/width/height fields can isolate part of a multi-monitor desktop.

Camera / capture card / OBS

Uses Windows DirectShow devices. Click Detect devices. Webcams, HDMI capture cards and OBS Virtual Camera may appear here.

Microphone or audio device

Records an audio input independently.

RTSP

Use an IP camera or streaming program address beginning with rtsp://.

Network stream

Use HTTP/HLS (.m3u8), SRT, UDP, RTP or another address FFmpeg understands.

Watched folder

When running, VIC copies new media files from the watched folder into VIC storage.
