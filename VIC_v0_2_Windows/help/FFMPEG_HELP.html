FFmpeg help

FFmpeg is the media engine VIC uses to read files, screens, cameras and network streams.

Automatic installation

Run INSTALL_FFMPEG.bat. It asks WinGet to install Gyan.FFmpeg.

After installation, close old Command Prompt and VIC windows. Run CHECK_SYSTEM.bat again.

VIC searches the normal PATH, its own tools folder and common WinGet package folders.

Local copy

You can place ffmpeg.exe inside tools\ffmpeg\bin\, or put its complete path in config\settings.json.
