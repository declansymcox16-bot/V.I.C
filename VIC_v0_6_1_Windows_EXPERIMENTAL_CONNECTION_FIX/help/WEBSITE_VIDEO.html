Website video and livestreams

This source type uses yt-dlp rather than passing the webpage directly to FFmpeg. It supports YouTube and many other websites, subject to each site's current support and permissions.

Private, age-restricted or account-only content may require cookies. This prototype does not include cookie-import controls yet.

Only ingest media you are entitled to access and record.

Single, playlist and upcoming-live modes

Single records one video or livestream page. Playlist stores every item separately and remembers completed item IDs so later starts skip duplicates. Upcoming scheduled live event keeps the worker waiting and checking until the event begins; Stop cancels the waiting job.

Use Test before Start. An upcoming-event test checks metadata without waiting for the event to begin.

Private, age-verified and signed-in content

VIC does not store your username or password. Choose Automatic browser fallback to try the source signed out first and use the selected worker PC's logged-in browser only when yt-dlp reports a login, age, private-content, members-only or authentication error.

Always use browser login is useful for private playlists where anonymous playlist processing may otherwise skip inaccessible entries. A cookies.txt file can be selected instead; its path must exist on the worker PC.

Account settings belong only to that one source. Other sources remain signed out unless you separately enable account use for them.

Opening the actual YouTube login screen

Choose the worker and browser, then press Open YouTube login window on selected worker. VIC opens the normal Google/YouTube sign-in page on that PC. Log in there, return to VIC, choose Automatic browser fallback or Always use browser login, and press Test.

VIC does not display an embedded password box and never receives your password. Account cookies are used only by sources where you enable them.
